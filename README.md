# DataCo Supply Chain BI Capstone

**DSA4157 Business Intelligence · 3DSA-2 Group 1**
Favorada, Ulrik Gabriyel · Lavado, Sean Eldridge · Uy, Shane Hans

## Data
- `DataCoSupplyChainDataset.csv`: 180,519 rows × 53 columns, one row per order item, Jan 2015 to early 2018.
## Data Model
- 21 tables built and cleaned in MySQL: one fact table (`fact_order_items`) and 20 dimension tables covering orders, customers, products, order destination and time.

## What's inside
- SQL - DATACO: the SQL scripts. Run them in order: 1, 2, 3.
- TABLES AND ERD: diagrams of the tables.
- DASHBOARD - WORKBOOK: the Tableau dashboard (open with Tableau).
- Report and slides: the PDF files.
